# CarDealer — учётная система автосалона

Настольное приложение для автосалона: витрина автомобилей для клиента и четыре
рабочих места сотрудников. Клиент бронирует машину без регистрации, дальше заявка
идёт по цепочке — консультант, кредитный отдел, оценщик trade-in — и заканчивается
договором в PDF.

**Стек:** C#, WPF (.NET Framework 4.8), Entity Framework 6 (Database First, EDMX),
MS SQL Server, iText 7 для генерации документов.

## Как это работает

**Витрина (без входа в систему).** Список доступных машин с фото и фильтрами по
марке, цвету, году и диапазону цены. Кнопка «Забронировать» просит ФИО и телефон,
создаёт заявку и убирает машину с витрины.

**Администратор.** Заводит и увольняет сотрудников (логин и пароль генерируются
автоматически по табельному номеру), добавляет машины в каталог вместе с фотографией,
смотрит аналитику за произвольный период: размер автопарка, число заявок, выручку
и топ-3 марки.

**Консультант.** Работает с очередью заявок. Может оформить продажу и сразу выгрузить
договор купли-продажи, передать заявку в кредитный отдел или оценщику, зафиксировать
отказ клиента. Если машина не подошла — подбирает похожие по выбранным критериям
(марка, модель, цвет, кузов, цена ±20%).

**Кредитный консультант.** Калькулятор с аннуитетным платежом. Ставка считается от
базовых 22% и корректируется сроком, размером первоначального взноса и наличием
страховки. По итогу — кредитный договор в PDF.

**Оценщик trade-in.** Принимает машину клиента в зачёт: заносит характеристики и фото,
считает доплату. Принятая машина автоматически попадает в каталог, а разницу клиент
может закрыть деньгами или кредитом.

## Роли и доступ

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `admin` |
| Консультант | `ivan` | `1234` |
| Кредитный консультант | `petr` | `1234` |
| Оценщик trade-in | `sergey` | `1234` |

Учётные данные тестовые и лежат в демонстрационной базе.

## Запуск

1. Выполнить `CarDealership.sql` в SQL Server Management Studio — скрипт создаёт базу
   `CarDealership` со схемой и демонстрационными данными.
2. В `CarDealer/App.config` указать свой сервер в обеих строках подключения
   (`data source=.` — локальный экземпляр по умолчанию).
3. Открыть `CarDealer/CarDealer.slnx` в Visual Studio, восстановить пакеты NuGet
   (`packages.config`) и запустить.

Генерация PDF использует `C:\Windows\Fonts\arial.ttf` — без него кириллица в
документах не отрисуется.

## Структура

```
CarDealer/
├── MainWindow          — витрина и бронирование
├── LoginWindow         — вход сотрудников
├── AdminWindow         — сотрудники, каталог, аналитика
├── ConsultantWindow    — заявки, продажа, подбор аналогов
├── CreditWindow        — кредитный калькулятор и договор
├── TradeInWindow       — оценка и приём авто в зачёт
├── BookingWindow       — диалог бронирования
├── PurchaseWindow      — выбор способа покупки
├── Model1.edmx         — модель БД (Database First)
└── *Converter.cs       — конвертеры для привязок XAML
```
